# CRUD Almacén

Sistema para gestionar productos desde la consola. Permite registrar nombre y cantidad de productos con persistencia en JSON.

## Tecnologías

- Python 3.14.3
- JSON

## Instalación

1. Clonar el repositorio:
   git clone https://github.com/tu-usuario/crud-almacen.git
2. Ejecutar:
   python main.py

## Uso

1. Agregar producto
2. Listar productos
3. Actualizar producto
4. Eliminar producto
5. Salir
